Stack Overflow

FR

1.User can add question which will have a title , body and a list of tag
2.User can add a answer for a particular question
3.one vote by a user for an item
4.author of the question can mark any answer as accepted
4.search a question by tag and optionally by a keyword in title

NFR

1.scale : system should be able handler increase number of question, answer and votes
2.Concurrency : system to be able to handle concurrent request on vote up and down
3.Extensible: system should handle different kinds of search
