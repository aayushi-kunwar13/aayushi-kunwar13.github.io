Parking Lot

Functional requirements

  1. Support multiple floors with each floor having mulitple parking spots of different sizes
  2. Support three vehicle types with fixed size: SMALL, MEDIUM , LARGE
  3. Each parking spot has a size , and can accommodate vehicle of equal or small size
  4. On entry, find a parking spot for the vehicle based on nearest-to-entry-point assignment , assign to the vehicle and create a ticket
  5. If there is no parking spot left return some message
  6. On exit, validate the ticket , calculate the parking duration and fee and release the spot and return fee amount

Non-Functional Requriements

  1. Handle concurrent request from multiple gate safely without assigning the same spot
  2. Extensible logic for payment calculation and spot assignment
  3. System should support addition of more spots and floors
