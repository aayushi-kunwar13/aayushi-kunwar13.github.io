Text Justification

Hard Strings / Simulation 43 lines Open problem ↗ View on GitHub ↗

Question

Pack words greedily into lines of exactly maxWidth characters. Spread extra spaces as evenly as possible (extra ones go to the left gaps); the last line and one-word lines are left-justified.

Key insight

Greedy: take as many words as fit, then distribute spaces = (maxWidth - letters) across the gaps. (Work in progress.)
