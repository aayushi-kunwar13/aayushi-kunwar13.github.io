Geospatial index

Understand when to use r-tree , quad-tree, geo-hash

geohash is just a string recompute on each location update (cheap, no structural rebalancing), whereas R-tree/quadtree need to physically restructure the tree as points move, which gets expensive at “every user’s location changes every session” scale.
