How do I add a problem here?

Just write it in IntelliJ and refresh this page. These folders are read automatically:

  • ~/Desktop/code_practice/src/main/java/com/practice/phonepe/questions: each package is an LLD problem
  • ~/Desktop/code_practice/src/main/java/com/practice/phonepe/interview: one LLD problem
  • ~/Desktop/code_practice/problems/src/main/java/lld: each package is an LLD problem
  • ~/Desktop/code_practice/problems/src/main/java/dsa: each file or folder is a DSA problem
  • ~/IdeaProjects/personalProject/miniproject/src/main/java: each package is an LLD problem

Optional: start a DSA file with a comment like /** Problem: Two Sum Link: https://… Difficulty: Easy */ to show a link and difficulty.
