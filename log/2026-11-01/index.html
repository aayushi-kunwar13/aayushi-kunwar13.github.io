IMC online assessment + BFS with a bitmask state

dsagraphsbfsbitmaskonline-assessmentimc

Focus areas: IMC online assessment (2 hours) and two grid problems.

IMC online assessment (2 hrs)

  • Tic-tac-toe: implement the game and its win/draw checks. Clean approach: keep row/column/diagonal counters (+1 for X, -1 for O) so each move is checked in O(1) instead of rescanning the board.
  • Find the bug: read existing code and fix the faulty logic. Things worth checking first: off-by-one bounds, wrong comparison operators, state not reset, integer overflow and null/empty inputs.
  • Simple DSA question.

DSA: grids

  • Shortest Path to Get All Keys: BFS where the state is (row, col, keysMask), with a 3D visited array [m][n][1 << k]. Picking up a key sets its bit, a lock is passable only if its key bit is set, and you stop when the mask equals all keys. Same idea as the obstacles-elimination problem from 10-31: put whatever changes your options into the BFS state.
  • Island Perimeter: no DFS needed. Every land cell adds 4, and every land neighbour above or to the left takes away 2 (one shared edge hides one side of each cell).

Pattern of the day

State = position + what you’re carrying. When the same cell can be reached with different “inventory” (keys, eliminations left), the BFS node must include that inventory, and a bitmask keeps it compact.
