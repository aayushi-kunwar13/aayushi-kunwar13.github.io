Inventory Management System

FR

1. We have a multi warehouse system which contains multiple product with its stock
2. Find product with a specific qty in warehouse with most stock for reservation and if not available then return a message “product not available”
3. Reserved order can be fulfilled or cancelled
4. remove from reserved state if no action happen within 15mins
4. Restock the product with specific qty to a specific warehouse
5. Trigger a notification if a product stock is less than threshold (keep threshold as configurable per product)

NFR

1.Scalable (data grow): system should handle addition of more warehouse/product
2. Extensible: find product logic should be swappable with other logic
3. Concurrency: Handle concurrent request for reservation of product coming from two different threads , also to handle concurrency between reservation vs reservation and restocking vs reservation
4.Scalable(expiry mechanism ): Expiry detection should be scale efficiently as active reservation grows
